# PowerS
Desktop audio player in C++ powered by raylib and BASS with 10-band EQ, FFT spectrum, and lyrics.
Все релизы сдесь: https://github.com/salamjop/PowerS/releases

Системные требования ОС: Windows (x64).   
Графика: требуется поддержка OpenGL 3.3 и выше. На старых видеокартах / драйверах с OpenGL 1.1 или OpenGL 2.1 плеер не запустится.
